# 🚀 Sovereign Health Agent 對話快捷指令指南 (Dialogue Commands Guide)

本檔案詳細列出 Sovereign Health Agent (主權健康代理人) 本地對話終端中所有支援的 `!sha_` 前綴快捷指令，說明其用途、操作流程與系統產出。

> **💡 阿喜伯的實踐故事：**
> 阿喜伯對電腦的黑底視窗與指令介面本來感到敬畏與害怕。但在兒子的引導下，他發現只要在對話框中輸入幾個簡單的 `!sha_` 指令，就能立刻完成繁雜的操作。比如輸入 `!sha_schedule`，AI 助理就會為他量身定做出一日服藥時間表；輸入 `!sha_myedu` 就會出來專屬的衛教摘要；當阿喜伯想研究新標靶藥物時，兒子在終端機輸入 `!sha_check`，台美三方的最新審查進度與健保藥價就一秒下載對位。這些快捷指令，讓阿喜伯擺脫了繁瑣的網頁點擊與檔案流浪，真正拿回了健康管理的自主權。

## 📌 指令總覽 (Commands Overview)

| **`!sha_myedu`** | 產製個人化衛教摘要卡 | 主動輸入 | 自動載入目前病歷資料，模糊查詢衛教庫，產出實證文獻與 AI 照護歸納雙防線。 |
| **`!sha_edu`** | 瀏覽與查詢本機衛教庫 | 主動輸入 | 列出本地所有已預載之病情與用藥衛教主題清單，可輸入編號查看細節。 |
| **`!sha_switch-demo`** | 雙軌展示/真實模式切換 | 主動輸入 | 一鍵物理隔離，清除資料庫真實病歷（保留 raw 備份），以進行安全物理隔離。 |
| **`!sha_drug`** | 藥品許可證衛教資訊查詢 | 主動輸入 | 輸入藥品許可證號或健保程式碼，從食藥署系統查詢成分適應症並存入 SQLite。 |
| **`!sha_verify`** | 本地主權健康離線查證工具 | 主動輸入或執行腳本 | 離線模糊查詢疾病、用藥歷史變更、醫師/醫院住院事件溯源與指標對齊。 |
| **`!sha_check`** | 連線三方即時對位查詢 | 主動輸入或執行腳本 | 連接美國 FDA、台灣 TFDA、台灣健保署 API，比對取得最新健保規定與藥價。 |
| **`!sha_schedule`** | 視覺化服藥排程與照護卡 | 主動輸入 | 讀取 SQLite 當前用藥，結合手冊大書安全規則，生成 24 小時用藥排程與警語卡。 |
| **`!sha_add_med`** | 口述用藥快速入庫補登 | 主動輸入 | 接收參數並生成標準 FHIR R4 JSON 資源，直接插入 SQLite 的歷程資料表中。 |
| **`!sha_trend`** | 臨床檢驗指標趨勢與就醫對齊 | 主動輸入 | 模糊搜尋 SQLite 檢驗，繪製歷史檢驗趨勢表，並自動與住院事件進行對照整合。 |

## 🧬 1. `!sha_hot` - 熱接入快速建檔 (Hot Ingestion)

* **用途**：當病患正面臨重大健康抉擇或急迫治療期（如確診、轉移、復發等關鍵窗口），協助病患或家屬在 3 分鐘內一次性填齊核心病歷，以便系統能立即進行台灣臨床試驗比對與第二意見文獻搜尋。
* **啟動方式**：
  1. **主動觸發**：在對話終端直接輸入 `!sha_hot`。
  2. **被動觸發**：在對話輸入中偵測到包含「確診」、「癌症」、「復發」、「轉移」、「骨髓瘤」等敏感詞時，Agent 會主動詢問使用者是否啟動熱接入。
* **收集問題 (4 大核心)**：
  - 【問題 1/4】：確診疾病與狀態（如：多發性骨髓瘤，第三期）
  - 【問題 2/4】：主要治療用藥，以逗號分隔（如：Daratumumab, Bortezomib）
  - 【問題 3/4】：看診之台灣醫院與科別（如：台大醫院血液科）
  - 【問題 4/4】：藥物或食物過敏史（如：無過敏史）

<details>
<summary>🛠️ 技術家屬區：資料庫寫入機制</summary>

* **資料庫寫入**：
  - 系統自動進行 PII 個資去識別化（主體指向 ID `Patient/AFU_004-DEID`）。
  - 將回答封裝為 Condition、MedicationRequest、Encounter、AllergyIntolerance 等標準 FHIR R4 JSON 格式，儲存於 `MY_CLINICAL_JOURNEY` 表中。

</details>

## 📖 2. `!sha_myedu` - 個人化衛教與用藥資訊摘要卡 (Personalized Education)

* **用途**：讀取患者本機 SQLite 歷程庫中已登錄的疾病與用藥，自動至本地衛教庫中進行比對檢索，產出專屬的個人化衛教與日常照護摘要。
* **啟動方式**：在對話終端輸入 `!sha_myedu`。
* **分流輸出規範**：
  - **【一、 資料庫權威實證資訊】**：直接印出 SQLite 庫中檢索到的文獻資料與出處標註（如 `[PubMed PMID: xxx]` ）。
  - **【二、 AI 智慧歸納與日常照護補充】**：AI 針對上述診斷與多藥聯用進行綜合照護提醒（例如手腳發麻水溫防燙傷、預防皮蛇抗病毒藥必須天天按時服用），並顯著標記此區塊為 AI 歸納，非原始文獻，僅供照護參考。
  - **【免責聲明】**：結尾處硬性印出繁體中文免責聲明。

## 🔎 3. `!sha_edu` - 瀏覽與查詢本機衛教庫 (Topic Browser)

* **用途**：允許病患主動檢視本機衛教庫（`MY_EDUCATION_BASE` 表）中所有預載的病情及用藥衛教清單。
* **啟動方式**：在對話終端輸入 `!sha_edu`。
* **操作流程**：
  1. 系統列出所有已預載之主題（如：多發性骨髓瘤症狀說明、萬科用藥須知等）。
  2. 使用者輸入主題對應之編號（如 `1`）。
  3. 系統輸出該條目的詳細文獻實證內容，並動態附帶 AI 日常照護重點叮嚀。
  4. 使用者亦可輸入 `Q` 結束瀏覽返回主對話。

## 🔄 4. `!sha_switch-demo` - 雙軌展示/真實模式切換 (Demo/Real Mode Switch)

* **用途**：在展示系統（Demo）與真實使用（Real Mode）之間切換。基於真實病患的隱私安全與本地個資防禦，本指令提供一鍵物理隔離機制。
* **啟動方式**：在對話終端輸入 `!sha_switch-demo`。

<details>
<summary>🛠️ 技術家屬區：物理安全防護與清除機制</summary>

* **物理安全防護機制**：
  - **切換至展示模式**：系統在清除真實病人資料前會向使用者進行確認。同意後，會自動清除 SQLite 資料庫（`fv_patient_personal.db`）中所有與真實病人 `AFU_001` 關聯的就醫歷程、用藥與檢驗。
  - **資料備份留存**：被清除的只是資料庫中的解析紀錄，儲存在 `data/raw/` 目錄下的原始健康存摺與檢驗明細檔案將被妥善保留，隨時可以重新匯入。
  - **Git 排除確保**：由於 `data/raw/` 目錄已完全在 `.gitignore` 排除，此操作可防止使用者在展示、測試時，不慎將真實病患的私密病歷 commit 並推送到 GitHub 等公開儲存庫。

</details>

## 💊 5. `!sha_drug` - 藥品許可證衛教資訊查詢 (Drug Query)

* **用途**：允許病患或家屬輸入台灣的藥品許可證號（如 `12000711` 或 `衛署藥輸字第024510號`）或健保用藥程式碼（如 `BC12601100`），自動檢索適應症、劑型與成分明細，並可格式化寫入本地 SQLite 衛教庫。
* **啟動方式**：在對話終端輸入 `!sha_drug [許可證號或健保碼]`。

<details>
<summary>🛠️ 技術家屬區：tw-med-db 本地離線優先與 Playwright 備援機制</summary>

* **雙軌秒級檢索機制**：
  - **本地大資料優先（首選路徑）**：系統預設優先探測 `tw-med-db` 本地醫療大資料庫。若環境中已啟用，直接在 5 毫秒內自 6.6 萬筆官方藥證庫中輸出完整中文品名、英文品名、許可證號、成分、核定適應症與劑型外觀，**完全免除瀏覽器啟動開銷與網路連線**。
  - **Playwright 爬蟲備援**：若本地未啟用大資料庫或查無紀錄，系統自動無縫切換為原有之 Playwright 無頭瀏覽器，前往食藥署線上系統抓取最新資料。
* **許可證號智慧轉換**：
  - 若輸入如 `內衛藥製字第000711號` 的中文許可證，系統會自動轉譯成食藥署內部程式碼 `12000711`。
* **資料庫寫入**：
  - 使用 `--save` 或 `-s` 參數時，查詢到的資訊將格式化為 Markdown 檔案，並儲存至本地端 SQLite 的 `MY_EDUCATION_BASE` 資料表，使後續的 `!sha_myedu` 能給出更為精準的照護提醒。

</details>

## 🔍 6. `!sha_verify` - 本地主權健康離線查證工具箱 (SHVT)

* **用途**：為了解決大語言模型 (LLM) 可能產生的醫療名詞、就醫資訊及用藥信度幻覺，本工具箱提供 100% 離線之本地 SQLite 資料庫與原始病歷檔案對照整合檢索，並原生融合 `tw-med-db` 全台藥證與 LOINC 檢驗大資料，能快速翻譯程式碼、查詢用藥變更史、追溯看診醫師與住院事件，並自動組裝產生指向權威第三方的實時查證連結。
* **啟動方式**：在對話終端輸入 `!sha_verify` 啟動對話式互動選單。

<details>
<summary>🛠️ 技術家屬區：CLI 腳本參數與四大離線查證機制</summary>

* **本地 CLI 執行**：在終端機直接執行 `python3 utils/health_query_tool.py [參數]`。
* **指令參數說明**：
  - `-i`, `--interactive`：啟動互動選單（無參數時預設此模式）。
  - `-d [疾病]`, `--disease [疾病]`：模糊查詢本機疾病衛教與臨床指引。
  - `-m [藥物]`, `--drug [藥物]`：查詢個人用藥變更軌跡，並自動融合 `tw-med-db` 官方藥證與健保價。
  - `-p [醫師/代號]`：檢索含有該醫師簽章之原始病歷，並 Join 住院事件對齊輸出。
  - `-c [程式碼]`, `--code [程式碼]`：優先比對 `tw-med-db` 之 M12 LOINC 檢驗碼與 M01 健保藥品碼，若無則平滑降級至本地字典備援。
  - `--no-med-db`：強制停用外部醫療大資料庫，切換為純本地離線字典模式。
  - `--with-med-db`：強制嘗試啟用外部醫療大資料庫。
* **四大核心離線查證機制 (硬性防幻覺)**：
  1. **疾病與指引**：顯示權威指南（如 NCCN, 台灣血液病學會）出處，防範口語化謬誤。
  2. **用藥歷史差分與大資料對照**：梳理劑量異動，針對停用藥物提供防幻覺提示，並補充全台官方藥證與核定適應症。
  3. **醫師原始病歷溯源**：在實體去識別化檔案（`data/raw/`）中進行全文檢索，找出該醫師簽章的原始病摘，並 Join 就醫事件 `Encounter` 顯示具體住院時間與片段。
  4. **檢驗指標與住院對齊**：查詢歷史數值時，自動比對就醫事件之時間區間。若該指標測量時間介於某次住院期間，系統將自動標註「此檢驗為某醫院住院期間進行」，協助患者建立時間軸對齊認知。

</details>

## 🌎 7. `!sha_check` - 連線三方即時對位查詢 (Tri-Authority Query)

* **用途**：免除人工前往各網站查對新藥的繁瑣手續。使用者只要輸入學名或商品名，即可在一秒內由後台直連下載並對位台美三大監管機構的最新藥品給付與許可證資料。
* **啟動方式**：在對話終端輸入 `!sha_check [藥名]`（如：`!sha_check Elranatamab`）。

<details>
<summary>🛠️ 技術家屬區：連線直連 API 與檔案下載機制</summary>

* **後台支援與執行機制**：
  - 調用實體腳本 [query_official_drug_db.py](../utils/query_official_drug_db.py)。
  - **美國 FDA**：透過 REST API 即時請求 OpenFDA。
  - **台灣 TFDA**：下載「未註銷/登出藥品許可證資料集」ZIP，自動解壓縮還原為 JSON。
  - **台灣健保署**：下載新版藥價 CSV，透過 Header Mapping 自動校正欄位偏移，進行學名與品名比對。
* **本地 CLI 執行**：在終端機直接執行 `python3 utils/query_official_drug_db.py --fda/--tfda/--nhi [藥名]`。

</details>

## 📅 8. `!sha_schedule` - 視覺化服藥排程與高階照護卡 (Medication Scheduler)

* **用途**：病患一鍵即可取得最符合臨床事實與個人化指引的 24 小時服藥清單，避免多種藥物同時服用產生的交互作用與生活困擾。
* **啟動方式**：在對話終端輸入 `!sha_schedule`。

<details>
<summary>🛠️ 技術家屬區：排程引擎規則與 SQLite 查詢</summary>

* **後台支援與執行機制**：
  - 提取 `fv_patient_personal.db` 中 `resource_type = 'MedicationRequest'` 且狀態為 `active` 的現有藥物。
  - 對照大書指引 [medication_import_guide.md](./ch04_medication_import_guide.md) 中的臨床警語與給藥時間點（例如：類固醇為了預防失眠，應於晚餐前或更早服用；B肝預防藥需空腹服用）。
  - 將資料與規則結合，輸出為精緻的 24 小時用藥時刻表。

</details>

## ✍️ 9. `!sha_add_med` - 口述自費藥歷快速補登 (Oral History Ingestion)

* **用途**：患者常有健康存摺中查無的自費藥品（如新藥）或口述歷史維持藥物。本指令讓病患或照護者可以直接以一句說話將用藥登錄進個人資料庫中。
* **啟動方式**：在對話終端輸入 `!sha_add_med [藥名/學名] [劑量] [頻率] [起始日]`（如：`!sha_add_med Cyclophosphamide 50mg QD 20180507`）。

<details>
<summary>🛠️ 技術家屬區：參數拆解與 SQL 寫入機制</summary>

* **後台支援與執行機制**：
  - 系統內建的對話器會攔截並拆解參數。
  - 自動呼叫 Python 腳本或由 AI 直接以 SQL INSERT 寫入 `MY_CLINICAL_JOURNEY` 表，產生標準的 FHIR R4 `MedicationRequest` JSON。
  - 補登完成後，會即時反饋並提示使用者再次執行 `!sha_schedule` 以載入新藥物。

</details>

## 📈 10. `!sha_trend` - 臨床檢驗指標趨勢與住院對齊 (Lab Indicator Trends)

* **用途**：病患不需繁瑣地逐頁比對紙本或電子病歷，一鍵即可掌握自身檢驗指標或血球的變化趨勢，並理解哪些是在住院治療期間發生的波動。
* **啟動方式**：在對話終端輸入 `!sha_trend [指標名稱]`（如：`!sha_trend WBC`）。

<details>
<summary>🛠️ 技術家屬區：Observation 與 Encounter 住院事件對照整合對位</summary>

* **後台支援與執行機制**：
  - 查詢 SQLite 中 `resource_type = 'Observation'` 的歷史資料。
  - 與就醫住院時間點（`Encounter` 資源）進行對照整合。
  - 自動列出日期、指標值、單位以及就醫狀態（例如：「日常門診追蹤」或「醫院住院期間對齊」）。

</details>
