# 📚 病患自主衛教與思辨指南 (Patient Health Literacy & Critical Thinking Guide)

本指南旨在幫助您與您的家屬，在面對龐大的醫療資訊與 AI 輔助回答時，建立**自主查證、理性思辨與精準醫病溝通**的能力。

拿回健康主導權的第一步，不是盲目相信 AI 或網路偏方，而是學會「如何有所本、如何自我思辨」。

> **💡 阿喜伯的實踐故事：**
> 阿喜伯在使用本地 AI 助理時，對助理提供的多發性骨髓瘤文獻來源產生了好奇。阿喜伯的兒子引導他一起閱讀本指引，上網輸入 PubMed 的 PMID 查詢文獻原文，比對研究對象的年齡與體表面積（BSA），並發現了文獻中提到的標靶藥物副作用發生率。隨後，阿喜伯在回診時，把助理產出的門診 SOAP 概況卡出示給主治醫師，並主動詢問了預防性抗病毒藥物與周邊神經病變的防範措施。醫師驚訝於阿喜伯的科學思辨能力與高度合作態度，花費了更多時間與阿喜伯細緻討論化療劑量的調整。這證明了「有所本的理性提問」能極大地提高醫病溝通品質。

---

## 🧭 序言：為什麼病人需要學習「自主思辨」？

AI 代理人（如主權健康助理）能快速從數百萬篇醫學文獻中為您檢索答案，但 AI 畢竟不是您的主治醫師，甚至有時會因為搜尋引擎的資料對位錯位，產生「張冠李戴」的數字幻覺。

為了確保您與家人的用藥安全性，病患本人與家屬必須具備「核心查證素養」。這不僅能防範 AI 幻覺，更能讓您在與主治醫師溝通時，成為一位「有備而來、高度理性」的合作夥伴。

## 🔍 第一階段：學會看懂並校驗 AI 的文獻來源 (PMID 識讀法)

當 AI 回答您的醫療諮詢時，會提供類似 `[PubMed PMID: 18711175]` 的標記。這就是醫學文獻的身份證字號。

### 🔎 如何自行校驗 PMID 的真實性？
1. **複製 ID 號碼**：將 `18711175` 這組 8 位數號碼複製下來。
2. **前往美國國家醫學圖書館 (PubMed)**：
   * 在瀏覽器中輸入網址：`https://pubmed.ncbi.nlm.nih.gov/` 加上該號碼。
   * 例如：[https://pubmed.ncbi.nlm.nih.gov/18711175/](https://pubmed.ncbi.nlm.nih.gov/18711175/)
3. **進行「語意交叉比對」**：
   * 開啟網頁後，查看英文標題（Title）與摘要（Abstract）。
   * **比對關鍵字**：確認文章中是否出現您的疾病學名（如 *Multiple Myeloma* 骨髓瘤）或藥物學名（如 *Bortezomib* 萬科）。
   * **揪出幻覺**：如果網頁打開，標題是關於植物、蝦子、或其他不相干的疾病，即代表 AI 發生了「PMID 錯位幻覺」，該文獻不可採信。

## 🇹🇼 第二階段：利用台灣官方管道查證用藥說明書與健保規定

在台灣就醫，最權威、最接地氣的藥物與費用資訊，全部公開在衛福部的官方系統中。

### 1. 查詢官方核准的藥物說明書（中文仿單）
當您想了解藥物最完整的適應症、用法用量、嚴重心血管或神經副作用、保存方式時，應查閱食藥署核准的官方仿單。
* 🌐 **查詢管道**：[衛生福利部食品藥物管理署 - 西藥許可證查詢](https://www.fda.gov.tw/MLMS/H0001.aspx)
* 📝 **操作方法**：
  * 在「中文品名」輸入商品名（如：`萬科`），或在「英文品名/成份」輸入學名（如：`Bortezomib`）。
  * 點擊進入許可證詳細頁面，下載下方的 **「仿單電子檔 (PDF)」**。
  * **思辨重點**：比對仿單中的「用法用量」與醫院藥袋上的指示是否相符。若有出入，應於回診時向藥師或主治醫師確認原因（有時醫師會根據病患生理特徵如體表面積 BSA 調整劑量，此為合理偏離）。

### 2. 查詢健保給付條件與價格
標靶治療費用高昂，了解健保給付規定是病患與家屬的財務防線。
* 🌐 **查詢管道**：[中央健康保險署 - 健保用藥品項查詢](https://info.nhi.gov.tw/INAE3000/INAE3000S01)
* 📝 **操作方法**：
  * 輸入藥袋上的 **「健保代碼」**（10 碼英數字）。
  * 查看 **「健保價格（健保價）」**，並點擊 **「給付規定」** 查看條文。
  * **思辨重點**：確認健保給付的臨床適應症條件。例如，健保是否要求先用過第一線藥物無效後，才給付目前的第二線標靶藥物？這有助於您與醫師討論自費與健保的銜接計畫。

## 🧠 第三階段：面對醫療資訊的思辨三問 (Critical Thinking)

不論是從 AI、社群網絡或親友口中聽到任何醫療照護建議，請在心中啟動以下三問：

1. **第一問：這項建議的「實證醫學等級」是什麼？**
   * *思辨引導*：這是一項大型多中心三期臨床試驗的結論，還是只是少數個案的經驗分享（如偏方、防癌茶等無文獻支援說法）？
2. **第二問：這項研究的對象，生理特徵與我相符嗎？**
   * *思辨引導*：文獻中的病患平均年齡是多少？他們的體表面積 (BSA) 與腎功能指標與我（如 68 歲、BSA 2.00 ㎡）一樣嗎？如果我的腎功能較差，是否必須減量以防毒性累積？
3. **第三問：這項藥物在台灣的臨床照護常規中，如何進行副作用的「預防性阻斷」？**
   * *思辨引導*：例如使用萬科時，文獻指出帶狀疱疹復發率高，那我的主治醫師是否已經幫我開立了預防性抗病毒藥（Acyclovir）？如果沒有，我是否應該主動詢問醫師？

## 💬 第四階段：與主治醫師的「精準對話」實踐

台灣的門診時間非常緊湊（平均每位病患僅有 3-5 分鐘）。如何利用您查證後的資訊進行高品質溝通？

### 📋 診間精準溝通 3 步驟：
1. **出示最新的 SOAP 概況卡**：將您最近的日常症狀自述（如半夜發燒、手腳發麻）印出或以手機出示，讓醫師在 10 秒內掌握最新客觀生理指標（BSA）與主觀症狀。
2. **針對關鍵副作用主動提問**：
   * *範例問法*：「醫師，我查閱了萬科的官方仿單與文獻，得知此藥容易引起手腳麻木。我最近雙腳腳趾開始有針刺感，這是否代表周邊神經病變正在累積？我們需要考慮調整劑量或改為皮下注射嗎？」
3. **核對預防性用藥**：
   * *範例問法*：「醫師，文獻提及使用此標靶療程時，帶狀疱疹復發率高，建議每天服用抗病毒藥預防。請問我目前的自備藥袋中，哪一顆是預防皮蛇的藥？我需要天天按時服用嗎？」

### 第五階段：自主檢驗病歷資料的國際合規性 (FHIR Validator)

為了確保您的個人健康資料在不同醫院與 AI 系統間能夠無障礙流通，本系統產出的病歷資料均完全符合 HL7 FHIR 國際標準與衛福部官方的 TW Core 規範。您可以自行下載國際官方驗證工具，來檢驗您自己匯出的健康資料 JSON 檔是否合規。

#### 📋 簡單驗證 4 步驟：

1. **一鍵下載官方驗證器**：
   在系統的子專案目錄下執行以下腳本，將自動建立 `bin/` 目錄並從 GitHub 下載最新版國際官方 Java 驗證器（此目錄已被設定為 Git 忽略）：
   ```bash
   ./scratch/download_validator.sh
   ```
2. **匯出病歷為 FHIR JSON 檔案**：
   執行以下腳本，將您的個人 SQLite 健康資料庫全量匯出為標準的 FHIR JSON 格式：
   ```bash
   python3 scratch/dump_all_fhir.py
   ```
3. **執行官方標準驗證**：
   執行以下 Java 指令（會自動加載台灣 TW Core 實作指引 IG，並使用 `-tx n/a` 離線模式排除國際術語伺服器的中文翻譯污染）：
   ```bash
   java -jar bin/validator_cli.jar scratch/fhir_validation_dump -version 4.0.1 -ig tw.gov.mohw.twcore -tx n/a
   ```
4. **結果解讀**：
   驗證完成後，若畫面結尾出現 `Success: 0 errors`，即代表您的健康資料在結構與核心欄位上 100% 通過國際互通性標準，為完美的綠燈資料，能安全地與任何相容 FHIR 的醫療資訊平台對接。
