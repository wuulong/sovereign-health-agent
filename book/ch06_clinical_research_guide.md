# 🌐 臨床科研檢索、衛教資訊與病情概況生成指引 (Clinical Research & Education Guide)

個人 AI 助理的核心目標之一是縮短醫病溝通的資訊不對稱。當病患下載此工具在本地端運行時，本指引將引導病患與家屬建立「主權科研自救能力」，主動檢索國際臨床試驗與最新醫學共識。

> **💡 阿喜伯的實踐故事：**
> 阿喜伯每次看診前，最頭痛的就是如何在門診短短的 3 分鐘內，跟醫師講清楚最近一個月吃癌德星與普力多寧類固醇的身體反應。阿喜伯的兒子利用本指南介紹的「臨床科研檢索與病情概況生成」工具，自動讀取本地資料庫，產生了一份無個資、帶有 PICO 邏輯的台灣在地臨床試驗檢索連結。同時，AI 助理在對話末尾依循「誠實問答規範」，誠實回答了關於某個偏方的未知（IDK）防線，並在最後一鍵產出了乾淨的 SOAP 門診溝通卡。阿喜伯把這張卡印出來帶去門診，醫師一目了然，極大地節省了問診時間，讓阿喜伯得到了更精準的照護。

## 🔬 1. 目的 (Objective)

在病患面臨重大疾病（如血液癌症）的關鍵決策點時，引導患者與照護者主動突破與大型醫療機構之間的資訊不對稱。透過結構化的方法（PICO 框架），向國際公開的臨床試驗與學術文獻資料庫要答案，自己尋找最新的療法與第二意見科學依據。

## 🗺 2. 檢索管道與指引 (Search Channels)

系統建議使用者透過以下三大國際公開管道切入檢索：

1.  **ClinicalTrials.gov (美國國家醫學圖書館臨床試驗註冊中心)**
    *   *目的*：尋找全球（特別是台灣本土）正在招募中、或即將進行的新藥、新療法臨床試驗。
    *   *指引*：為了讓檢索結果具備實務可行性，搜尋時必須限制 **Location（地理位置）為 "Taiwan"（預設地理限制）**，確保患者能就近參與試驗，免去跨國求醫的物理阻礙。
2.  **PubMed / MEDLINE (生物醫學論文資料庫)**
    *   *目的*：尋找同儕審查（Peer-reviewed）的最新醫學文獻，了解特定藥物的療效資料與國際臨床指引。
    *   *指引*：使用疾病的 MeSH（醫學主題詞）來進行檢索，可大幅過濾無效論文。
3.  **NCCN Guidelines (美國國家綜合癌症網絡患者指引)**
    *   *目的*：獲取全球癌症治療的黃金標準共識，核對目前醫院給出的治療方案是否符合最新的國際標準路徑。

## 🧠 3. AI 搜尋式生成程序 (Agentic Query Generation Procedure)

當 Agentic AI 接收到使用者「想要查詢最新療法」的意圖時，應遵循以下步驟進行推理與對話引導：

*   **PICO 因子對話提煉 (Intent Extraction)**：Agent 應與使用者進行語意互動，逐步提煉出 PICO 檢索因子：
    *   **P (Patient/Problem - 患者與疾病)**：疾病名稱（如 `Multiple Myeloma`）、基因分型或狀態（如 `Relapsed/Refractory`）。
    *   **I (Intervention - 擬採用新療法)**：感興趣的新標靶、免疫治療或新技術（如 `CAR-T`、`Dara-RD`）。
    *   **C (Comparison - 對照組)**：目前的標準療法。
    *   **O (Outcome - 關注指標)**：患者最關心的療效（如 `MRD` 陰性率、存活率）。
*   **同義詞擴充與 MeSH 對位 (Query Expansion)**：民眾輸入的疾病常是中文，AI 必須在本地對應出精確的英文醫學主題詞。例如將 `多發性骨髓瘤` 擴充為 `Multiple Myeloma`；`大腸癌` 擴充為 `Colorectal Neoplasm`。
*   **台灣地理定位與篩選條件注入 (Location Filtering)**：拼接 ClinicalTrials 檢索詞時，必須剛性注入 `&locn=Taiwan` 的參數。拼接 PubMed 檢索詞時，主動限制最近五年內發表及人類實驗，以確保文獻時效。

### 💻 檢索腳本工具使用手冊 (CLI Script User Guide)

本專案在 [`utils/query_generator.py`](../utils/query_generator.py) 部署了一個多資料庫科研檢索 URL 產生器，支援從本地 SQLite 資料庫讀取病歷，或手動透過命令列參數傳參查詢。

#### ⚙️ 命令列參數說明 (CLI Options)

| 短參數 | 長參數 | 類型 | 說明 | 範例 |
| :--- | :--- | :--- | :--- | :--- |
| `-d` | `--disease` | String | 指定患者診斷/疾病名稱。若提供此參數則略過讀取 SQLite 診斷。 | `-d "大腸癌"` |
| `-i` | `--drug` | String | 指定主要介入藥物/療法。若提供此參數則略過讀取 SQLite 用藥。 | `-i "Cetuximab"` |
| `-l` | `--location` | String | 限制臨床試驗地理位置。預設為 `Taiwan`。 | `-l "United States"` |
| `-b` | `--dbs` | List | 指定要啟用的搜尋資料庫。預設為 `all`。 | `-b ct pm gs` |
| | `--db-path` | String | 手動指定 SQLite 個人病歷資料庫路徑。 | `--db-path "./db/my.db"` |

> 支援的資料庫代號（可複選，以空白篩選）：
> * `ct`: ClinicalTrials.gov (美國臨床試驗註冊中心)
> * `pm`: PubMed (生醫論文資料庫)
> * `gs`: Google Scholar (Google 學術搜尋)
> * `cochrane`: Cochrane Library (系統性文獻回顧)
> * `tw`: 台灣本土臨床試驗平台查詢指引 (包含 CDE 與 TFDA 入口網)

#### 📖 典型使用場景與範例指令 (Usage Examples)

1. **自動讀取本地個人病歷**：直接執行腳本，系統會自動搜尋本地預設的 SQLite 資料庫進行個人化 PICO 檢索：
   ```bash
   python3 utils/query_generator.py
   ```
2. **手動隨選查詢**：當您想為親友或特定醫學問題進行隨選查詢，不需修改資料庫，直接傳入疾病與藥物：
   ```bash
   python3 utils/query_generator.py -d "大腸癌" -i "Cetuximab"
   ```

#### 🛠 簡單除錯指引 (Debugging Guide)

1. **檢索結果為 0**：PICO 的 `I` 寫得太過狹隘（例如把複方寫在一起 `"Daratumumab AND Bortezomib"`），請在命令列中放寬搜尋條件，只指定疾病。
2. **疾病英文翻譯不精準**：編輯 `query_generator.py` 中的 `DISEASE_SYNONYMS` 字典，手動追加您要搜尋的疾病中文與其英文 MeSH 詞彙。

## 🧠 5. 有所本生醫 QA 與誠實問答規範 (Grounded Medical QA & Honesty Guidelines)

當個人醫療 AI 助理與使用者進行醫學疑問對答時，必須嚴格遵守以下「實證醫學」與「誠實原則」的行為規範，以防止 AI 幻覺對患者健康產生誤導。

### 📌 規範一：無檢索，不回答 (Search-Before-Answer)
* **要求**：Agent 在回答任何涉及疾病或治療的問題前，必須先調用本地或外部資料庫的文獻及指引。嚴禁直接根據語言模型的內建權重記憶進行未經實證的解答。
* **行為**：在回答前，大腦必須先向使用者印出「正在為您檢索本地及外部權威生醫文獻資料庫...」之程序提示，以昭公信。

### 📌 規範二：嚴格標註出處來源 (Strict Citations)
* **要求**：所有醫療回覆中，每一點核心醫學結論（如療效、適應症、副作用）都必須以中括號標註明確的科學文獻來源或指引條目。
* **範例**：`...能顯著延長無惡化存活期。[文獻出處：PubMed PMID: 27557302, NCCN 癌症治療指引 2026]`

### 📌 規範三：未知問題之誠實認錯 (Honesty Rule / IDK)
* **要求**：若檢索結果顯示資料不足、查無文獻支援，Agent 必須誠實地回答「**不知道**」，絕對禁止虛構、猜測或合理化偏方。
* **誠實話術範本**：
  > 「對不起，阿喜伯。我檢索了 PubMed 與本機醫學指引資料庫，找不到關於您詢問內容的足夠權威實證醫學文獻。本著醫療安全原則，我『不知道』這個問題的確切醫學答案，也無法為您提供任何建議。如果身體感到任何不適，建議您直接向您的主治醫師或藥師進行諮詢，切勿聽信偏方。」

### 📌 規範四：剛性附帶免責聲明 (Disclaimer Barrier)
* **要求**：每一輪醫療諮詢對話的末尾，必須剛性附帶以下繁體中文免責聲明：
  > **【主權健康助理免責聲明】**  
  > 本助理所提供之醫學資訊僅供科研與衛教參考，不能替代專業醫師的診斷、治療或醫學建議。任何用藥與治療方針調整，請務必與您的主治醫師進行討論確認。
